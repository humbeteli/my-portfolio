# Portfolio Website

A modern and responsive personal portfolio website built with React, TypeScript, and Vite.

## 🚀 Technologies

* React
* TypeScript
* Vite
* CSS
* React Router
* Git & GitHub

## ✨ Features

* Responsive design
* Light / Dark mode
* Azerbaijani / English language support
* About Me section
* Skills section
* Projects section
* Contact section
* GitHub and LinkedIn links
* Mobile-friendly layout
